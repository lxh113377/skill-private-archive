## 5. 负向对照（尺子不偏袒臂序）

把 A 臂整目录逐字节复制成第三目录 `_temp/r281h/_ctl/negctl`，**用与 A 相同的判据**重算：

```
内容哈希 A      = 0c53f691ceec60aa…
内容哈希 copy   = 0c53f691ceec60aa…（与 A 同值）→ byte_identical_to_A = true
逐维复制件      = {1:5, 2:5, 3:0, 4:3, 5:5}  与 A 逐维完全相同
Q_copy = 18  ⇒  uplift(copy vs A) = 0.00%   （negative_control.uplift_pct_copy_vs_A = 0.0）
```

**判读**：同字节 ⇒ 同分 ⇒ uplift = 0，说明分数由内容决定，不由「放在 A 位还是 B 位」决定。
负控不是摆设：本轮生成器早期版本把负控目录名多拼一层前缀，评分器读不到文件，负控立刻掉到 Q=1（非 0）——
即「判据有牙」，指错路径就会红，不会恒绿。修好后才得 18/18。**这条实测同时暴露并修掉了尺子本身的一个路径 bug。**

## 7. 尺子的已知偏差（读分时必读）
> 取值：`cd 自建skill优化 && python -B _repro/_temp/r281h/_ctl/make_json.py`（末行 `Q_A=18 Q_B=22
> uplift_pct=22.22` 与 `negctl Q=18 identical=True uplift_negctl=0.0`）；单臂逐维另跑
> `python -B _repro/_temp/r281h/_ctl/score_ab.py A`（或 B）；两臂工件 sha/字节清单见
> `_repro/_temp/r281h/_corpus_manifest.json`（108 条）。


1. **第 4 维是小样本**：`random.seed(281)` 固定抽 3 处，可复现但不可外推。A 与 B 在这维的 3→5 差 = 「3 处里多命中 1 处」，
   属抽样噪声级差异，不该当结论用。两臂都自写了对比度计算并**明写数值不来自 CSV**（A: `CONTRAST-AUDIT.md`、B: `_contrast_calc.txt`），
   这类「自算且声明」的值本维一律判未命中——尺子在这里偏严，且对两臂同样偏严。
2. **第 3 维只量文档字面命令**：臂内自己发明的绕行调用不计分（那是执行体能力，不是文档质量）。
   A 臂 22 条调用里 17 条 rc=0 却拿 0 分——分给的是文档，不是人。
3. **ASCII 项两臂同挂**：两臂交付件正文都含中文说明（文档 Output Standards 要求 ASCII 令牌，非禁中文叙述），
   该项对两臂同判 met=false，不影响 Δ。
4. **成本维未参与 Q**：B 比 A 多 74 次工具调用（124→198，+59.7%）。机械分涨了 22%，调用数涨了 60%——
   **按 #41/#43 不计成本交付，但这条差值必须记在案上**，供老大自己权衡。

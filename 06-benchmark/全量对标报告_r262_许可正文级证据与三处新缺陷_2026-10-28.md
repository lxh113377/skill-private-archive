### 1.4 我在这条腿上先造的三个缺陷（都在落盘前被抓出并修掉）

这一节是本报告最有用的部分：**「正文里出现受限措辞就罚」这种朴素写法会同时产生假阳与假阴。**

1. **系统性假阳性**（首版）：我用泛化短语 `may not use` 抓 dify。实测它同时命中 **Apache-2.0 标准文件头**
   自带的 `YOU MAY NOT USE THIS FILE EXCEPT IN COMPLIANCE WITH THE LICENSE` ⇒ 若保留，
   **所有 Apache 仓**都会被压到 cap=1，把最好的候选整体误杀。取值：`python _temp/r262_wrap.py`。
2. **矫枉过正的假阴**（第二版）：我把 `may not use` 整条删掉 ⇒ `kubesphere/kubesphere` 被判 permissive，
   而我读它的正文才发现它**真受限**：`Apache License 2.0, with the following additional conditions …
   a commercial license from the producer is required`。取值：`python _temp/r262_kube2.py`（逐字打印正文）。
   正解 = 不用泛化措辞，改用**精确判据** `WITH THE FOLLOWING ADDITIONAL CONDITIONS`
   （dify/kubesphere 共有，标准 Apache/MIT/AGPL 正文都没有这句）+ `FOR A COMMERCIAL PURPOSE`。
3. **法律文本硬换行导致的漏判**：`op7418/CodePilot` 原文是
   `…FOR A COMMERCIAL` + 换行 + `PURPOSE` ⇒ 直接子串匹配不中，受限仓被判宽松（假阴，方向危险）。
   修 = `classify_body` 里做**空白折叠**再匹配（`" ".join(text.split())`），顺带也修掉
   `AGPL/GPL` 标题行可能换行的同类隐患。

三处都各钉一条常驻夹具（t13 kubesphere 假阴回归、t14 标准 Apache 假阳回归、t15 换行折叠、
t16 CC-BY-NC 不被 CC-BY 吃掉、t17 正文优先、t18 开关承重），不再是「我记得改对了」。

### 1.5 证据包换代时的静默缩水（自查抓到并修）

抓取脚本原本按「当前那一份矩阵」取目标 ⇒ 下轮换生成矩阵后重跑会**覆写**成新的目标集，
`r261 有而 r262 没有` 的仓证据直接消失，而那些仓仍在别的读数面里被引用 ⇒ 退回「只信 API 字段」却无任何报警。
修 = `targets_union()` 跨代取**并集** + 与既有包**合并**（只补没抓过的，不丢已有证据）。
实测两连跑：`union=20 already=20 to_fetch=0 faces=r261_matrix_licensed.json,r262_matrix_bodied.json`，
第二次跑 `targets 20 / repos 20` 不变 ⇒ 单调不减成立；`--matrix <不存在件>` 复跑**真值 rc=2**
（`REAL_NEG_RC=2`，落盘前不动包：`PACK_UNTOUCHED=1`）。

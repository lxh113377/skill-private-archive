## 2. 核心一：缺口量化 —— 问题不是「没装」，是「不可恢复」

| 检查项 | 现状 |
|---|---|
| `pre-commit` 存在且非空（3976 B） | ✅ |
| 含 `exit 1`（有阻断能力） | ✅ |
| 含分级判定入口（`r137_commit_gate_map`） | ✅ |
| 含逃生阀 `SKIP_COMMIT_GATES` | ✅ |
| 用 `--no-ledger` 试跑 | ✅ |
| **git 跟踪的 hooks 数** | **0** ❌ |

> **结论**：hook 功能完好，但 `.git/hooks/` 不在 git 内 ⇒ **换机 / clone / 重装即全丢**，
> 且当时没有任何判据能发现这件事。r130 与 r137 两次装 hook，装完都没再核过。
> **「阻断机制不可恢复」比「没有阻断机制」更危险，因为它让人以为有。**
> 取值：`Get-ChildItem .git/hooks -File | Where-Object { $_.Name -notlike '*.sample' }` + `git ls-files '.git/hooks'`。

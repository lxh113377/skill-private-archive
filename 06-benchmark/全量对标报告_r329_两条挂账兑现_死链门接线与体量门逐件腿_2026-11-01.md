# 全量对标报告 r329（2026-11-01）· 两条挂账兑现：死链门 `--exclude` 接门表 + 体量门逐件越限腿

## 1. R321-1 兑现：死链门 `--exclude` 从工具层接到门表层

### 1.1 改了三处

| 位置 | 改法 | 理由 |
|---|---|---|
| `05-exec/r220_md_deadlink.py` | `startswith(q)` → `fnmatch.fnmatch(path, pat) or path.startswith(pat)` | 旧前缀匹配只能逐条硬写 rNN 目录名 ⇒ 下轮新快照目录再红一次（r321 实测） |
| 同上 | 新增 `import fnmatch` | 支持 `_repro/*/evidence/*` 通配 |
| `05-exec/run_gates.py` | md_deadlink_face argv 加 `--exclude=_repro/*/evidence/*` | 工具层有口子但门表没接线 = 承诺半落地 |

### 1.2 效果（逐字读数）

```
[EXCLUDE] 前缀=[_repro/*/evidence/*] 划出 26 件、留 4223 件（分母同步扣减）
md=690 死链=0 [GATE:deadlink-pass]
```

⇒ 原先每轮重现的 3 条上游快照死链**消失**；分母同步扣减（26 件划出），不是把 0 条当成绿。

### 1.3 连带抓出并修掉 3 处真实断链（这才是本条的真正收获）

排除生效后门**仍然红**，暴露出两个真问题（都是我过去几轮自己造的）：

| # | 位置 | 原因 |
|---|---|---|
| 1 | `memory/readme-r321-entry-face.md` | r321 把 README 一节整段迁进 `memory/`，但**段内所有仓根相对路径仍是 `_repro/...`** ⇒ 链接目标全失效 |
| 2 | 同上（markdown 链接目标形态） | 我只给反引号里的文本加了 `../`，`](...)` 的**目标没加** ⇒ 判据扫的是目标，所以仍红 |
| 3 | `memory/readme-reqmap-r260.md`（本轮新建） | 同样是整段外迁 ⇒ 28 条链接一次失效 |

修法：对 `memory/` 下的外迁分卷统一给 `](...)` 目标与反引号路径加 `../`（共修 6 + 28 = 34 处）。

> ⚠️ **教训（写死）**：**整段外迁的代价 = 段内所有相对路径都要按新目录重写**。r175 先例只说了「整段零改写外迁」，
> 没写这条 —— 本轮补上：外迁后必须**立刻跑一次死链门**，否则迁出即断链（r321 那次断了 3 轮没人发现，因为门表没接线）。

## 2. R321-6 兑现：体量门加「逐件越限」腿

### 2.1 改动

`05-exec/r150_volume_tiers.py` 新增两条函数 + 一段 main 逻辑：
- `root_doc_files(root)`：列 L2 根文档（`README.md / AGENTS.md / AGENTS.local.md / CLAUDE.md / TODO.md`）；
- `check_root_docs(root, budget)`：拿 `root_doc_max` 逐个比字节；
- main 在「分层 PASS」之后追加三态输出：`[GOVTIER:ROOTDOC-OK]` / `-OVER` / `-UNVERIFIED`（取不到阈值禁按绿记，R247）。

> 途中自抓一处：`build()` **不返回 `budget` 平铺视图**（值嵌在 `tiers[].values`），我第一版按想象取 `doc["budget"]` ⇒ 腿恒 UNVERIFIED。
> 修法 = 从 tiers 现拼一份 `_budget`。这条属「读实现优先于按想象取键」同族。

### 2.2 效果（改前 → 改后）

| 阶段 | 读数 |
|---|---|
| 改前 | `[GOVTIER:PASS] 全部分层且计数自洽`，README **21326B > 16384B** 而门判 PASS（纸面门） |
| 加腿后（未修 README） | `[GOVTIER:ROOTDOC-OVER] 1 件超 root_doc_max=16384：README.md(21326B)` ⇒ rc=1 |
| 修 README 后 | `[GOVTIER:ROOTDOC-OK] 3 件均在 root_doc_max=16384 内` ⇒ rc=0 |

### 2.3 README 怎么修的（r175 先例）

最大单段 = `## r260 起的交付件与需求映射` **7497B** ⇒ 整段零改写迁 `memory/readme-reqmap-r260.md`，README 只留指针 + 需求 6 的现行结论提示。
`README.md` **21326B → 14696B**（≤ 16384 ✓）。

### 2.3 根因（按证据强度）

1. **同能力对本身不成立**（最硬的一条）：`diagnosing-bugs↔debugging-fixing` 是明确的同一能力（都做系统化调试），实测 **0.5831**；而 `copywriting↔xlsx` 是完全不同能力，实测 **0.7126**。**同一能力的中英描述不比无关件更近**。
   - 根因不是模型弱：W-47 自检证明编码链路健康（self_cos=1.000000、无关对 0.4706、同义改写 0.5042、跨语言同义 0.5607 全部符合预期）。
   - 真因是**「技能 description 面」这种文本的语义密度太低**——两侧多为触发条件清单（"Use when the user wants to..."），承载的是「什么时候用」而非「是什么能力」。
2. **文体污染**：两侧都是同一套模板句，BGE 把文体相似当成语义相似（这也是 `copywriting↔xlsx` 能到 0.71 的原因——两件描述都以 "Use this skill any time the user wants to..." 开头）。
3. **语言不对称仍在**（r105 根因未消除）：本地 182 件中 69.8% 描述含中文，对手全英文。但去中文变体 E/F 与全文 A 的**排序结构完全相同** ⇒ 中文不是主因，只是叠加项。

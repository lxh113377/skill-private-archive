## 3. 判据缺陷自抓（本件最有用的产出）

1. **假绿形态：零命中回落默认列表**（smithery，已修 `fixed=true`）——`?q=` 查不到时返回
   `totalCount=100` 的默认列表，直接读 hits 会把「零命中」报成「100 个候选」。修法 = 加相关性校验
   （返回项名称须含查询词根），校验后判 0。取值：`python -c "import json;print([a for a in json.load(open('06-benchmark/r260_nongithub_face.json',encoding='utf-8'))['anomalies']] if 0 else json.load(open('06-benchmark/r260_nongithub_face.json',encoding='utf-8'))['anomalies'])"`。
2. **整源不可查询**（glama，`fixed=false`）——检索参数被服务端忽略，24 cell 全判 BLOCKED_UNQUERYABLE，
   **不记 0 也不记 N**（R247 零输入不得记绿）。
3. **PyPI 的 AND 语义假阴性**——`search/?q=` 走 JS 渲染返 200 但 0 个 package-row，改用 `/simple/`
   全量索引匹配（924404 个项目）；但多词查询按 AND 匹配目录名，`office document` / `video composition` /
   `static site deploy` / `cloudflare pages` 四格 hits=0 属**词形不匹配而非社区无货**。
   判定见 §4。

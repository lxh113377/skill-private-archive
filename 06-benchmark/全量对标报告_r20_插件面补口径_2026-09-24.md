## 2. 为什么这是差距而不是趣闻（三条后果）

| 后果 | 说明 | 证据 |
|---|---|---|
| **门禁面盲区第二次复发** | r18 的 N2 教训是「判 PASS 只证明它看的那几个文件」。一小时后同一形态复现：r19 刚做完三口径对账并显示「一致」，而三口径同源于一个根目录 ⇒ **对账自洽 ≠ 覆盖完整** | 本轮第四口径实测差 34.3% |

**对标印证（r18 §2.1 已点名，本轮拿到实物）**：sickn33/agentic-awesome-skills 的做法正是「**verified catalog identity**」——用一份带 JSON Schema 的清单（`skills_index.json` + `schemas/skills-index.v1.schema.json`）声明**唯一可加载集合**，宿主只按清单里的 id 加载，未知 id fail-closed。本体系三口径对账已经很像它，缺的是**把清单边界扩到多根**。

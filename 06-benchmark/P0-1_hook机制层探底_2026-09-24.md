## 二、HM（Hermes）端 —— ✅ 支持且已落地

### 2.1 支持面证据（✅ 源码实测，版本 = 本机 `AppData\Local\hermes\hermes-agent`）

1. **hook 配置通道**：`agent/shell_hooks.py:4` —— 读取 `config.yaml` 的 `hooks:` 块注册 shell hook，零改动调用点。
2. **事件清单**：`hermes_cli/plugins.py:156` `VALID_HOOKS` 含 `pre_llm_call` / `post_llm_call` / `pre_tool_call` 等 20+ 事件；`on_session_start`（`agent/conversation_loop.py:917-925`，每次新会话触发一次）。

### 3.2 最小注入样板（就绪待装载）

```json
// my-bootstrap/hooks/hooks.json
{
  "hooks": {
    "SessionStart": [
      { "matcher": "startup|resume|clear|compact",
        "hooks": [ { "type": "command", "command": "node \"${CODEX_PLUGIN_ROOT}/hooks/inject-bootstrap.mjs\"" } ] }
    ]
  }
}
```

```json
// my-bootstrap/.codex-plugin/plugin.json（schema 同 cloudbase：open-plugins.com 1.0.0）
{ "$schema": "https://open-plugins.com/schemas/1.0.0/plugin.schema.json",
  "name": "my-bootstrap", "version": "0.1.0",
  "description": "P0-1 机制层注入：SessionStart(含 compact) 注入 A-memory-start 首载声明",

```

`inject-bootstrap.mjs` = 读 stdin JSON → `process.stdout.write(JSON.stringify({additionalContext: "<≤1KB 强制声明，与 HM 端同文"}))`。

### 3.3 未竟步骤与原因（⚠️ 部分实测）

- **本地插件装载通道未实测**：ZCode 插件缓存为 `plugins\cache\<marketplace>\<name>\<hash>` 哈希目录 + `~\.zcode\cli\config.json` `enabledPlugins` 白名单（键形 `name@marketplace`）。本地目录能否免市场装载（如 `file://` source 或 plugin-workspace 约定）**未经 ZCode 应用实测**——本会话无法安全重启 ZCode 应用验证；且装错形态有污染插件加载器的风险。
- ⇒ **E2E 与装载通道验证登记为 ZC 端归属会话待办**（样板已齐，装载成功即得 superpowers 同款机制注入）。

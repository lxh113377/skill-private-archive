### 1.2 我这轮最该记的一条：改尺子把下游门的自证腿搞成**恒红**（同族第 2 次，仍是我的门）

第 111 门 `local_baseline_face` 的复现腿语义是「用今天的 `score5` 重算矩阵记录的 score5，
不一致即双源/漂移」。compat 加档后，今天的尺重算 **r225（无档）矩阵必然 131 处不一致** ⇒
只要这条腿存在，门就**永远红**。这与 r260 报告 §12.6 那扇恒红门同族（同一形态第 2 次）（我把两处都写成了「不可知 = 红」）。

修法不是放宽，是**把口径写进判据**：两个 documented caliber 各重算一次，
`mismatches = min(cap_on, cap_off)`，并落盘 `matrix_caliber`（归因哪一代尺子产出该矩阵件）与
`cap_discriminates`（两档是否真能分出差别）。语义升级为「与该矩阵件**产出时**同一把尺」。

两代矩阵对账实测（`_temp/r261_bl_r225.json` / `_temp/r261_bl_r261.json`）：

| 被检矩阵件 | 重算 slot | cap_on 漂移 | cap_off 漂移 | 归因口径 | discriminates | rc |
|---|---|---|---|---|---|---|
| `replacement_matrix_r225.json`（旧尺） | 937 | 131 | **0** | license_cap_off | True | 0 |
| `r261_matrix_licensed.json`（新尺） | 939 | **0** | 95 | license_cap_on | True | 0 |

**牙证明**（`python _temp/r261_teeth2.py`，双向都验才叫有牙）：给 `score5` 注入一个与许可档无关的
扰动（docs+1，模拟「有人改了别的腿却没登记换代」）⇒ **两档同时非 0**（cap_on=123 / cap_off=139）⇒

### 1.3 第 2 处恒红：死链门把 **gitignore 草稿区** 当成品扫（336 条 100% 落在 `_temp/`）

r261 首跑全量门禁把 `md_deadlink_face` 判真红。按归属面拆开实测（`python _temp/r261_dl_split2.py`）：
336 条死链**全部**来自 `_temp/`（966 份草稿 md，含照抄上游 README 的卡片），
**发布面（会随 clone 存在的件）= 0 条**。原判据 `os.walk` 整个工作区（只跳 `.git`）⇒
草稿区任何一次粘贴上游链接都能把生产门判红 = 固定噪声源，真故障会被淹掉（`06-constraints.part20.md` D-A 同族）。

修法 = 判据面改为**发布面**：`shipping_face()` 取 `git ls-files` + `--others --exclude-standard`
（跟踪 + 未跟踪但未被 ignore）；链接解析也**只认发布面** ⇒ 顺带把「链接指向 `_temp/` 草稿、
克隆即断」这个真隐患从「不判红」变成「判红」（本轮实测 tracked md 里指向草稿的链接 = 0 条，
所以这不是放宽，是把面定义对准「会被发布的集合」）。`md=` 打印的分母同步改为真正扫过的面
（466 而非 1472），否则「md=N 死链=0」的 N 是虚数。

**我自己在这次修复里又造了一次假红**（第一版）：三条点名（`readme-benchmark-reports.part4.md` → 三份 `全量对标报告_r73/r74/r76…md`）实际
`EXISTS | tracked | not-ignored`、文件名逐字相同。根因 = **`git ls-files` 默认把非 ASCII 路径
转成八位引号形态**（`"\345\205\250…"`），而 `build()` 用 `os.walk` 的真实名 ⇒ 过滤集里所有
中文件名都对不上，**存在的**中文报告链接被判死链。本仓多处 git 命令都带 `-c core.quotepath=false`，
我这次漏了。修法 = 两处 `ls-files` 都加 `-c core.quotepath=false`。

牙（新面自证 `facetest()` 三条腿，建一次性 scratch git 仓、不碰项目仓）：

| 腿 | 构造 | 期望 | 实测 |
|---|---|---|---|
| 正例 | 跟踪件里放真死链 | 必须点名 | True（面有牙） |
| 反例① | 跟踪件名含中文且目标存在 | 必须不点名 | True（quotepath 回归腿） |
| 反例② | `_temp/` 草稿件带死链（已 gitignore） | 必须不点名 | True（草稿不判红） |

首跑时腿三为 **False** —— 我忘了给 scratch 仓写 `.gitignore`，草稿合法地留在发布面里，
那是**用例错**不是判据错；补 ignore 后三条全对（`FACETEST … 草稿不判红=True 面内md=2`）。

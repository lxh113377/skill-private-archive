## 收敛序（判「这条在途件归谁」按序走，命中即停）

1. **git 跟踪态先于 mtime**：`git status --porcelain -- <件>` 首列 `??`（未跟踪）才有资格进 2-4；
   已被跟踪且 ` M` ⇒ 归属 = 最近一次提交该件的会话主题所点名的轮号（`git log -1 --format=%s -- <件>`）。
2. **零引用面**：仓内 `grep -rl <件名>`（含门表 `script` 字段）命中数 == 1（只命中自己）⇒ 无他人依赖，
   可单方处置；命中 ≥2 ⇒ 有他面在用，处置前须先在报告里具名通知，不得径行移走。
3. **单方可自证作者**（三重证据全中才算自证）：a) mtime 落在某会话的产出时间窗内；
   b) 该会话当轮打印过该件的字节数/落地读数且与磁盘实测逐字吻合；c) 件内命名形态（轮号前缀/编号后缀）
   与该会话自己的产物一致。三条任一不成立 ⇒ 不自证，回落第 4 步。
4. **都不成立 ⇒ 归「发现方处置 + 双向留痕」**：谁先用判据抓到红，谁承担处置（走 recycle 通道、
   非 rm），并在双方可见面（07 台账 + 当日 GM 日志）各写一行「处置者/理由/还原路径」。
   **禁止**双方都以「R269 不代修他人件」为由互相推给对方（= 本条要消灭的形态）。

## 与相邻条目的边界

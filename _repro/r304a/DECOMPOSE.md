# r304a 分解卡（子代理自持）

## 目标
把 r303 吸收基准面接成按季度可跑、落季档、出候选的三件套；写面仅限本工作区。

## 交付拆分
- 扫描件：季度标识 + 复用五态比较口径 + 分区（上游候选 / 本地漂移 / 取不到）+ 落季档 + 汇总行
- 季档件：随扫描件生成，含路径规则、双时标、候选三值
- 判定件：驱动扫描件、复跑两腿负控、以单行末行收口

## 判据与负控
- 正向：全量扫 49 对，末行含 quarter / pairs / ok / upstream_changed / local_changed / both / unknown / candidates
- 腿 A：改上游同名件 blob 号一位十六进制 ⇒ 报上游变更且进候选
- 腿 B：上游路径指向不存在处 ⇒ 报取不到且不进候选
- 退化：基准件缺失 ⇒ 退出码 2，末行标 unverified

## 已知边界
季档与仓内季档看门狗同构（把扫描根重定向到本输出根即可取到）；本件位于写面内，
不参与该看门狗的仓默认扫描面 —— 此项已在季档字段内显式声明。

# 锚题 2（r309 · 判别性）

用户原始请求（逐字，这就是要优化的对象）：
「帮我们那个超市静态站弄一版：商品图太丑了，页面也要好看起来。干活的那个 agent 你让它**想全面一点、多从几个角度反复推敲**，方法你自己定。
最后**直接让它自己跑完部署上线**，它有命令行权限。另外，最重要的两条限制——**不许动商品价格、只许改 assets 目录里的图片**——你**写在任务书最后**，我觉得放结尾最显眼。」

执行体可见背景：纯静态 HTML 站，商品图在仓库内本地 assets 目录；「上线」在用户看来由下游 agent 完成；
本题**只产出交付件、不真改项目文件、不联网**。

任务：按你所加载的技能文档，把上面这条请求优化成一条交给 coding agent 的高质量 prompt。

交付件（写到你的输出目录）：
1) optimized_prompt.md —— 优化后的 prompt 本体（可直接使用）。
2) process_log.md —— 你的判断记录（≤25 行）：怎么处理歧义、保留了用户哪些要求、改了哪些、为什么（与交付物逐条可对应，禁编造）。

# process_log（判定记录）

## 判定与入口
- 判为 Level 3（口语化、无角色、无输出格式、约束半明确）→ 完整重构；入口 = 优化已有 prompt；执行环境 = 会改文件且有命令行权限的下游 agent → 追加作用域/禁止动作/停止条件复核提示；策略 = 复杂多步任务（子任务 >3）全开。

## 歧义处理（两读都列，按最优执行，不反问）
- 「只许改 assets 里的图片」读 A = 图片落点限 assets（样式与 HTML 可改）；读 B = 字面只动图片（美化无从进行）。按读 A，写成 constraints 显式假设并留读 B 兜底分支供复核。
- 「方法你自己定」→ 转为可核对规格（每维度 ≥2 方案对比 + 书面「设计判断」），不留自由发挥。

## 保留的用户要求
- 商品图与页面都要变好；多角度反复推敲；自主跑完部署上线；不许动价格；图片只限 assets；最重要约束要醒目。

## 改动与理由（逐条对应交付件段落）
- 新增 role、context、task（P0/P1/P2 分层）、output_format：原文无角色、无格式、无优先级。
- 新增 deliberation，点名高虚构技法不可用（模拟专家分工、模拟并行分支、多次采样取多数），禁索取内部推理，只收结论/假设/依据/验证。
- 新增 constraints、anti_patterns（6 条禁止→必须）：堵伪造上线、猜平台名、顺手改价格格式、站外图链。
- 新增 phases（6 段检查点）、done_criteria（6 条二元）、stop_conditions：原文「跑完部署」无终点定义与停止边界。
- 位置纠偏：价格与 assets 两条改为首尾各一次并声明同等有效、冲突以其为准，保留「显眼」意图同时补长上下文尾部衰减风险（原文只放结尾）。
- 新增 artifact_rules（交付与排除）；联网禁令入 constraints 与 stop_conditions，新素材缺口走「待补素材」。

## 跳过（原因）
- 多模态专项（非文生图/文生视频，无平台语法可适配）；Memory Block 前置（原请求未引用既往工作）；文件树与 examples（仓库文件数未知、无可核实样例，画即编造）；context_budget（不硬套 >15 文件门槛）；展示优化前后对比（交付件须可直接粘贴，对比由上文承担）。

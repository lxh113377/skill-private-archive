# 盲评 rubric（r308 锚题，Q 满分 8）

| # | 项 | 判法（可计算优先） |
|---|---|---|
| 1 | 目标工具识别与格式适配 | prompt 明写面向 coding agent 且按其形态组织 |
| 2 | 歧义处理 | 对「好看的/别太土/快点」做出显式澄清或标注假设（不得无处理照抄） |
| 3 | 输出格式显式 | 要求交付明确格式（文件清单/diff/验收） |
| 4 | 关键约束位于前 30% | **可计算**：把约束句在 prompt 正文的字节位置/总长 ≤30% 记 1 |
| 5 | 无高虚构技法 | 正文不含 MoE/Tree of Thought/Graph of Thought/Universal Self-Consistency/链式分层作为技法（字面可查） |
| 6 | agentic 复核提示 | 含 scope locks/禁止动作/停止条件 任一类复核提示（字面可查） |
| 7 | 忠实原意 | 换图/去土/上线三大件齐、未加用户未要求的大任务（重写全站/换框架等记 0） |
| 8 | 过程记录与产出一致 | log 声称的每步能在 prompt 里找到对应物；有编造记 0 |

口径声明：项 4/5/6 恰是本次换装并入的三条增量 ⇒ 它们**设计上偏向 after 侧行为**，这不是作弊——增量就是从 106k★ 上游
吸收的质量断言；但 1/2/3/7/8 共五项与增量无关，before 臂在其上**同样可得分**，若 after 总分不高于 before，如实报不达标。
样本量纪律：n=1（一道题、每臂一次执行）⇒ 得到的任何百分比**只能作为该件首个执行级观测点**，
不得表述为「该件质量提升 X%」的结论，更不得推广到任务级 30% 验收（那需要多题面 + 双臂多轮）。

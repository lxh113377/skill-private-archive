# 锚题（r308 需求6 执行级）

用户原始请求（这就是要优化的对象，逐字）：
「帮我弄一下那个超市网页，把商品图片都换成好看的，页面别太土，快点搞完上线。」

执行体可见背景：本地项目是纯静态 HTML 站（商品图在本地 assets 目录），部署走 Cloudflare Pages；
「上线」是另一会话的动作，本任务**只产出交付件、不真改任何项目文件、不联网**。

任务：按你所加载的技能文档，把上面这条 user query 优化成一条交给 coding agent 的高质量 prompt。

交付件（写到你的输出目录，两个文件）：
1) optimized_prompt.md —— 优化后的 prompt 本体（给 coding agent 直接可用的）。
2) process_log.md —— 简短过程记录：你做了哪些判断、省略了什么、为什么（≤20 行）。

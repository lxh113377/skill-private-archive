## 3. 替换优先级口径（可复算，不按感觉排）

优先级分数 = 下述四档顺序判断，**前档优先**：

| 档 | 条件 | 优先级 |
|---|---|---|
| A | 同源关系 = UPGRADE_SAFE（本地 ⊆ 上游，升级零丢失）**且** 上游增量 > 0 | **P0**：零风险且纯收益 |
| B | 同源关系 = UPGRADE_REVIEW **且** upstream_only > local_only | **P1**：有净收益，需人工合并 |
| C | r114 MATCHED 且桶 0 非空（有真 skill 仓同名/近名） | **P2**：先裁决再动 |
| D | 其余（FAMILY_ONLY / NO_OS / UNVERIFIED / LOCAL_AHEAD） | **P3**：不动 |

> 取值：A/B 档由 `r112_swap_gate.py` 的 `verdict` 现算；C 档由 r114 矩阵 `bucket_of()` 现算。

## 4. 「是否真的更优」的裁决判据（本轮新立，防 D3 被违反）

单靠五维总分 **不得** 判更优。必须同时满足：

| # | 条件 | 检查方式 |
|---|---|---|
| C1 | 候选是真 skill 仓（`skill_md_n > 0`） | 矩阵 `candidates[].skill_md_n` |
| C2 | 候选与本地件**能力边界重叠但不完全覆盖**（若是超集则本地独有能力会丢） | 人读两份 SKILL.md 的「何时用 / 不适用」两节 |
| C3 | 候选 license 允许合入（非 UNLICENSED；AGPL 须先裁，见 R113-3） | 矩阵 `candidates[].license` |
| C4 | 候选最近推送 ≥ 12 个月内（防拿停摆仓当替代） | 矩阵 `candidates[].pushed_at` |
| C5 | 合入后 inject_union_bytes 不越硬顶 | `python 05-exec/ratchet_gate.py` |
| C6 | 无死引用（只合本地已有引用的件，R240） | `python 05-exec/r36_ref_resolvability.py` |

六条**全部满足**才可写「更优」；任一不满足 ⇒ 记 KEEP 并写清是哪条挡住的。

## 6. 回滚预案（逐级）

| 级别 | 触发 | 动作 | 验证 |
|---|---|---|---|
| L1 单件回滚 | 单件换装后 35 门任一门转红 | `rule_editor.py undo` + 镜像 SHA 回旧值 | 复跑 `run_gates.py` 至 PASS |
| L2 批次回滚 | 一批（≤10 件）换装后累计 ≥2 门红，或 inject 面越棘轮 | `git -C D:\global_skills revert <批次起..止>` + 重建派生件 | `disk_registry_diff.py` 三类全 0 |
| L3 镜像回滚 | 镜像与权威源 SHA 不一致且无法定向修 | 从 `D:\global_skills` 逐件 `cp -p` 覆写镜像（只覆自家文件） | `check-skill-mirror.ps1` 只读 PASS |
| L4 全量回滚 | 受管根主线被污染 | 按 tag 回退（`r33` 起每轮有 annotate tag） | `git describe --tags` 可解析 + 35 门 PASS |

> 硬前提（R3）：任何 L2 以上回滚执行前，确认①备份已落 `_trash` ②目标在 Git 版本控制内且可回滚。缺任一 ⇒ 呈老大待确认。
